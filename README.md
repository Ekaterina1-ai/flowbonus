# FlowBonus

Веб-сервис бонусной платформы: лендинг, личный кабинет клиента и кабинет партнёра.

## Быстрый старт

```bash
cd server
pip install -r requirements.txt
python app.py
```

Откройте в браузере `http://127.0.0.1:5500`.

## Что внутри

- `index.html`, `clients.html`, `partners.html` — публичные страницы
- `cabinet/` — личный кабинет клиента
- `partner-cabinet/` — кабинет партнёра
- `server/` — Flask API + SQLite
- `server/flowbonus.db` — база с тестовыми кабинетами (для ознакомления)
- `css/mobile.css`, `cabinet/css/mobile.css` — отдельная мобильная вёрстка

## Тестовые данные

В репозиторий включена рабочая SQLite-база `server/flowbonus.db` с уже созданными тестовыми профилями (в т.ч. партнёр «Норма Тела», Волгоград). Войдите теми же логином/паролем, что использовали при локальной разработке.

## Важно

Это демо-репозиторий для просмотра кода и локального запуска. Позже сервис будет выложен на постоянный сервер.
